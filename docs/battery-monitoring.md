# Battery monitoring

The shared device model reserves optional aggregate, transmitter, and receiver battery information. An empty value means telemetry is unavailable or has not been investigated; it never means 0%.

No device battery telemetry backend is implemented yet. On the Windows development machine, WMI exposes a system battery instance (`ACPI\\PNP0C0A\\1_0`) only; that value belongs to the laptop and is not assigned to any microphone or headset. The paired Sony WF-C710N has Windows Bluetooth/HFP/AVRCP PnP functions but no active WASAPI capture endpoint and no associated WMI battery instance. The USB receiver exposes mouse, consumer-control, and vendor-defined HID collections, but standard PnP power properties contain no charge percentage. A different paired BLE device's Battery Service is not evidence for this headset. Values for the headset and USB wireless receiver therefore remain unknown, never copied from the laptop or another nearby device. Raw HID reports remain to be investigated before concluding that the receiver provides no telemetry.
